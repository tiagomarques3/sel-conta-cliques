# 🚀 NovoContaClique

> “Automatizar é transformar cliques repetitivos em tempo livre.” 😎

Bem-vindo ao **NovoContaClique**, um projeto de automação de testes criado para explorar o poder do Java + Selenium + Cucumber com uma pitada de coragem, café e bugs inesperados ☕🐞

---

# 🧪 Sobre o Projeto

O **NovoContaClique** é um projeto de automação de testes desenvolvido com foco em:

- ✅ Testes automatizados Web
- ✅ Estrutura moderna com Java 21
- ✅ BDD com Cucumber
- ✅ Execução com JUnit 5
- ✅ Selenium WebDriver
- ✅ Organização e escalabilidade

Aqui, cada cenário automatizado é uma batalha vencida contra os testes manuais repetitivos 💥

---

# 🛠️ Tecnologias Utilizadas

## ☕ Java 21
Projeto desenvolvido utilizando a versão mais moderna do Java.

## 🌐 Selenium WebDriver
Automação de navegação, interação e validação de elementos web.

## 🥒 Cucumber
BDD na prática!  
Porque escrever:

```gherkin
Dado que o usuário acessa o sistema
Quando ele realiza o login
Então o acesso deve ser permitido
```

é muito mais elegante 😌

## 🧪 JUnit 5
Gerenciamento e execução dos testes automatizados.

## 📦 Maven
Responsável por gerenciar dependências e manter a sanidade do projeto.

# ▶️ Como Executar o Projeto

## 1️⃣ Clonar o repositório

```bash
git clone https://github.com/seu-usuario/NovoContaClique.git
```

---

## 2️⃣ Entrar na pasta

```bash
cd NovoContaClique
```

---

## 3️⃣ Executar os testes

```bash
mvn test
```
